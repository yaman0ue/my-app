## 機能：

**ユーザーストーリー**
ブラウザのタブを整理したい。
なぜなら、タブを溜め込んでしまうため、見栄えが悪い、どのタブを保存したかったのかわからなくなるから、またブックマークで保存するほどではない。

**受け入れ条件（これができたら完成）**
- [ ] ログイン機能をつけて、個々で管理、ログインしていない人は参照できない
- [ ] URLを入力して保存、一覧から削除できる
- [ ] 保存からの経過時間の計測し、一覧で表示できる
- [ ] タグ付けをし、そのURLがどんなものかを分別できる

---

## やらないことリスト
- タブの自動取得、自動削除(セキュリティ上難しい。)
- スマホアプリ化（web上で十分）
- 通知（整理したいのが目的であるため、特に入らない）
