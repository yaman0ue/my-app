## 機能1：グループ・カテゴリー分け

**ユーザーストーリー**
エンジニアといっても、SQLやプログラミングなどさまざまな種類があるため、グループ分けをする必要がある。

**受け入れ条件（これができたら完成）**
- [ ] グループごとのフォルダの作成・削除できる
- [ ] 作成したフォルダに名前をつけることができる
- [ ] 作成したフォルダの中にさらに作成できる

## 機能2:いいね機能

**ユーザーストーリー**
たくさんの記事が投稿された時、どの記事がいい記事かがわからなくなる。

**受け入れ条件(これができたら完成)**
- [ ] 投稿されたコメントにいいねをつける・外すことができる
- [ ] つけられてるいいねの数を確認することができる

## 機能3:記事の投稿

**ユーザーストーリー**
その分野に詳しい方のお薦めする記事はとても説得力があるため

**受け入れ条件（これができたら完成）**
- [ ] 記事のタイトルを入力できる
- [ ] UELを登録できる
- [ ] 記事の説明やおすすめ理由を入力できる
- [ ] 投稿した記事の編集・削除ができる
- [ ] 誰が投稿したのかを確認できる

## 機能4:コメント

**ユーザーストーリー**
実際の声があると、想像しやすいため

**受け入れ条件（これができたら完成）**
- [ ] 投稿した記事にコメントを投稿できる
- [ ] 投稿されたコメントを一覧で確認できる
- [ ] 投稿したコメントを削除・編集できる

## 機能5:ブックマーク

**ユーザーストーリー**
気に入った記事は覚えるよりも、何かしらの形で残す方が後々見返しやすい

**受け入れ条件（これができたら完成）**
- [ ] 記事をブックマークできる
- [ ] ブックマークした記事を保存・確認することができる
- [ ] ブックマークを解除できる

## 機能6:有識者認証機能

**ユーザーストーリー**
投稿された記事が本当に信頼できるものなのか判断したい。そのため、専門知識を持つ人が投稿した記事なのかを確認したい。

**受け入れ条件（これができたら完成）**
- [ ] 管理者が有識者のアカウントを認識できる
- [ ] 認証されたユーザーには認証マークを表示する

## 機能7:記事の信頼性

**ユーザーストーリー**
投稿された記事が本当に適切なものなのか判断したい。

**受け入れ条件(これができたら完成)**
-[ ] URLが正しく開けるのかを確認できる
-[ ] ユーザーによる評価やいいねの数でつけられるタグが信頼できる〜問題ありで変わる

## 機能8:ログイン機能

**ユーザーストーリー**
自分の投稿やいいね、ブックマークなどを管理するために、アカウントを作成した方がいい。

**受け入れ条件(これができたら完成)**
- [ ] メールアドレスとパスワードを登録できる
- [ ] 登録した情報でログインできる
- [ ] ログアウトできる
